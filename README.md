# أساطير عوالم الظلال الكونية

لعبة استراتيجية ومغامرات فضاء عربية (RTL) تعمل بالكامل دون إنترنت، داخل تطبيق أندرويد.

## الأقسام

1. **سفينة القيادة الأم** — الملاحة بين المجرات، رادار التهديدات، التجهيز والدروع، توزيع الطاقة، المسيرات الذكية.
2. **إدارة الكواكب والمستعمرات** — الموارد الاستراتيجية، الإنشاء العمراني، التجارة والتحالفات، الزراعة، إعادة التدوير.
3. **بنات الأكوان والموضة** — استوديو الأزياء، الصالون، القصر الملكي، المسابقات الأسبوعية، استوديو الصور.
4. **المعارك وحروب الظلام** — غرفة العمليات، حلبة الدفاع، الألغاز الأثرية، المبارزات، أبراج الليزر.
5. **التطوير والتقنيات المحظورة** — المعمل السري، أكاديمية القادة، مختبر الطاقة المظلمة، الأرشيف القديم.
6. **المهام والقصة** — المهام الرئيسية، المهام اليومية، الإنجازات، الأحداث الموسمية.

## التقنية

- WebView + HTML/JS/CSS في ملف واحد، حفظ التقدم في `localStorage`.
- صوت محلي عبر TextToSpeech العربي، ومؤثرات صوتية من `assets/sfx`.
- بناء APK تلقائي عبر GitHub Actions على كل دفعة إلى `main`، ونشره في وسم `latest`.

## البناء

```bash
gradle assembleDebug
```

أو نزّل أحدث نسخة من صفحة الإصدارات.
